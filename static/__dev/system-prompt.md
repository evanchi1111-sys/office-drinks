我想要製作一個辦公室飲料訂購 web app,需有飲料店家飲料清單匯入功能,單位、姓名清單修改編輯。

使用者與需求(全部介面使用繁體中文,台灣用語):
- 同事用手機從 LINE 點連結直接使用,完全不需要登入或註冊帳號。
- 管理者(用一組管理密碼解鎖)才能修改飲料店菜單、單位與姓名名單;一般同事只能點餐。
- 飲料店菜單:可新增店家,匯入方式有貼上文字/Excel 複製的儲存格、上傳 CSV(要處理 Big5 編碼)、以及上傳菜單照片或 PDF 讓 AI 辨識(若平台提供 AI 能力)。菜單可有多個規格欄位(例如中杯/大杯),品項、價格、規格都能直接編輯、新增、刪除。
- 單位與姓名名單:新增/改名/刪除單位,新增/修改/刪除人員,可批次貼上或上傳 CSV 匯入(格式:單位,姓名1,姓名2…),可合併或取代。匯入後永久保留。
- 開團:管理者或任何人可選一家店開一團(有名稱,例如「10/6 飲料團」),可結束訂購、重新開放、刪除整團。
- 點餐:選單位 → 選姓名(或手動輸入)→ 選飲料 → 規格 → 甜度(正常糖/少糖/半糖/微糖/無糖)→ 冰量(正常冰/少冰/微冰/去冰/常溫/熱)→ 備註。每人杯數不限,可編輯或刪除自己的訂單。
- 常點的一鍵再訂:選好姓名後,列出該人過去點過、這家店還有賣的飲料,一鍵再訂一杯或帶入表單。
- 目前訂單依單位分組顯示,彙總各品項杯數與總額,並列出名單上還沒訂的人。
- 彙總可複製成文字(給店家),明細可複製成 Tab 分隔(貼到 Excel)。
- 可下載/列印分發單:第一頁是品項彙總,之後每個單位一頁,每人一列並有簽收框與小計,A4 列印版面。
- 視覺:清爽的茶飲店風格,手機優先,字體清楚。
