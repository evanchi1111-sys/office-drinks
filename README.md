# 辦公室飲料訂購

同事用手機從 LINE 點開連結,就能直接訂飲料。**不用登入、不用註冊帳號。**

正式網站:https://office-drinks.floot.app

## 這個程式是做什麼的

這是給辦公室揪團訂飲料用的網頁。管理者先把飲料店菜單和各單位的人員名單準備好,之後只要「開一團」,同事就能從 LINE 的連結進來點餐,最後可以一鍵整理成給店家的訂單,也能印出分發單。

## 功能

### 管理者功能(需要輸入管理密碼)

- 修改飲料店菜單:新增店家、編輯品項、價格與規格(例如中杯、大杯)、加料。
- 修改單位與人員名單:新增、改名、刪除單位,新增、修改、刪除人員。
- 菜單匯入,有四種方式:
  - 直接貼上文字
  - 從 Excel 複製儲存格後貼上
  - 上傳 CSV 檔(支援 Big5 編碼)
  - 上傳菜單照片或 PDF,由 AI 自動辨識
- 人員名單匯入:貼上或上傳 CSV(格式:單位,姓名1,姓名2…),可選「合併」或「取代」。

### 開團

- 選一家店開一團(有名稱,例如「10/6 飲料團」)。
- 可以挑選這一團要參加的人,系統會列出「還沒訂」的人。
- 可以結束訂購、重新開放,或刪除整團。

### 點餐流程

單位 → 姓名 → 飲料 → 規格 → 甜度 → 冰量 → 加料 → 杯數 → 備註

- 每人杯數不限,可以編輯或刪除自己的訂單。
- 常點的飲料可以一鍵再訂:選好姓名後,會列出這個人以前點過、而且這家店還有賣的飲料,按一下就再訂一杯。

### 彙總與輸出

- 依單位整理訂單,顯示各品項杯數與總金額。
- 「複製給店家」的文字(內含店家電話),可直接貼到 LINE 傳給店家。
- 明細可複製成 Tab 分隔格式,直接貼到 Excel。
- 可列印的 A4 分發單:第一頁是品項彙總,之後每個單位一頁,每人一列,有簽收欄與小計。

## 專案結構

```
pages/       頁面(目前只有首頁)
components/  畫面元件(點餐、彙總、菜單管理、名單管理、各種按鈕與對話框等)
helpers/     共用的小工具(訂單計算、菜單解析、資料連線、主題等)
endpoints/   後端功能(讀取資料、儲存店家、儲存名單、管理訂單與開團、AI 辨識菜單、檢查管理密碼)
static/      靜態檔案
base.css     全站的顏色與字體
```

## 資料表

**shops(飲料店)**

| 欄位 | 說明 |
| --- | --- |
| id | 編號 |
| name | 店名 |
| phone | 電話 |
| sizes | 規格清單(jsonb) |
| items | 品項清單(jsonb),格式 `[{n, p:[價格或 null]}]` |
| toppings | 加料清單(jsonb),格式 `[{n, p}]` |
| created_at | 建立時間 |

**units(單位)**

| 欄位 | 說明 |
| --- | --- |
| id | 編號 |
| name | 單位名稱 |
| members | 人員名單(jsonb) |
| ord | 排序 |

**sessions(開團)**

| 欄位 | 說明 |
| --- | --- |
| id | 編號 |
| title | 團名 |
| shop_id | 店家編號 |
| shop_name | 店名 |
| status | 狀態(開放中 / 已結束) |
| participants | 參加的人(jsonb,可為空,空代表全部人員) |
| created_at | 建立時間 |

**orders(訂單)**

| 欄位 | 說明 |
| --- | --- |
| id | 編號 |
| session_id | 所屬的團,對應 sessions;刪除整團時,訂單會一併刪除 |
| unit | 單位 |
| name | 姓名 |
| item | 飲料 |
| size | 規格 |
| price | 價格 |
| toppings | 加料(jsonb) |
| sugar | 甜度 |
| ice | 冰量 |
| note | 備註 |
| created_at | 建立時間 |

## 重要提醒

- **管理密碼(`ADMIN_PASSWORD`)是在 Floot 裡設定的機密資料,絕對不要放進這個程式庫。**
- AI 辨識菜單使用的是 Floot 提供的 `@floot/ai`。
- 這個程式庫只是專案的「版本備份」。網站實際上是在 Floot 上執行與發佈的,所以在這裡修改後,要把內容貼回(同步到)Floot,再重新發佈,網站才會真的更新。

## 修改流程

1. 在這個程式庫修改檔案,並提交紀錄(commit)。
2. 把修改過的檔案內容貼回 Floot 專案中相同路徑的檔案。
3. 在 Floot 確認畫面正常後,按「發佈」,正式網站就會更新。
4. 如果是直接在 Floot 修改的,記得也把結果同步回這個程式庫,兩邊才不會不一致。
