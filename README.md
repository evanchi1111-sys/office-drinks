# 🧋 辦公室飲料訂購

辦公室團購飲料：開團 → 分享連結到 LINE → 同事各自點餐 → 彙總給店家 → 列印分發單。同事不用登入、不用註冊帳號。

網站：https://evanchi1111-sys.github.io/office-drinks/

- **開團**：選飲料店與這次參加的人（名單上所有人，或勾選指定成員），可分享 `?g=團編號` 連結
- **訂購**：選單位與姓名（會記住）、搜尋品項、規格／甜度／冰量／加料／備註、一次多杯；「常點的」一鍵再訂；可修改、刪除自己的訂單
- **還沒選購**：依單位列出還沒點的人，點名字可直接幫他點
- **彙總**：品項杯數與金額、複製彙總（給店家）、複製明細（貼 Excel）、列印／下載 A4 分發單（第一頁彙總，之後每個單位一頁含簽收欄）
- **菜單**（需管理密碼）：店家、電話、規格、品項價格、加料；可貼上 Excel 或上傳 CSV（支援 Big5）匯入
- **名單**（需管理密碼）：單位與姓名，可批次匯入
- 多人同時使用時即時同步

純 HTML / JavaScript，放在 GitHub Pages；資料庫與即時同步使用 [Supabase](https://supabase.com)。

> 想先看看？網址後面加上 `?demo` 就是示範模式（資料只存在瀏覽器分頁裡，管理密碼 `demo1234`）。

## 安全規則
- 所有寫入都經過資料庫函式檢查，網頁無法直接改資料表。
- 杯價由資料庫依菜單計算（含加料），不採用瀏覽器送來的價格。
- 團結束訂購後，訂單不能再新增、修改或刪除（需先「重新開放」）。
- 菜單與名單需要管理密碼；密碼加密儲存，錯 5 次鎖 5 分鐘。
- 開團、結束訂購不需要密碼。團不能刪除，只能「結束訂購」，訂單紀錄會一直保留。

## 設定
可與桌球系統共用同一個 Supabase 專案（本系統資料表以 `od_` 開頭）。
1. **SQL Editor** → **New query** → 貼上 [`supabase/setup.sql`](supabase/setup.sql) → **Run**。
2. 設定管理密碼：把 `setup.sql` 最後一行（第 6 段）去掉開頭的 `--`、換成你的密碼，單獨執行一次。之後要換密碼也一樣。
3. [`js/config.js`](js/config.js) 填入 Project URL 與 publishable（anon）key。
4. 倉庫 **Settings** → **Pages** → Branch `main`、`/ (root)`。
